Isolated face-detection technical probe

This directory is development-only and is not imported by the product builder.
Acquisition occurs before packaging. Generated probe HTML contains all runtime,
model, license and notice bytes; inference has no network dependency.

1. TensorFlow.js 4.22.0 (Apache-2.0)
   https://github.com/tensorflow/tfjs/tree/tfjs-v4.22.0
   Exact archive/runtime pins: ../embedding/tfjs.dependencies.json
   The complete Apache text and THIRD_PARTY.TFJS.txt from that research directory
   are embedded in every generated probe document.

2. @tensorflow-models/face-detection 1.0.3 (Apache-2.0)
   Copyright 2024 Google LLC. All Rights Reserved.
   https://github.com/tensorflow/tfjs-models/tree/master/face-detection
   Exact npm archive and asset pins: dependencies.json
   The original Google Apache license header is preserved in the embedded bundle.
   Bundled TypeScript helpers (tslib 2.4.0) have the notice below. The MediaPipe
   runtime package is not installed or embedded: only runtime:'tfjs' is used.

3. MediaPipe face-detection TFJS short/full, version 1 (Apache-2.0)
   https://www.kaggle.com/models/mediapipe/face-detection/tfJs/short/1
   https://www.kaggle.com/models/mediapipe/face-detection/tfJs/full/1
   dependencies.json retains the reviewed exact Kaggle instance/version/license
   evidence, archive digests, model JSON digests and weight digests separately.
   No photograph, identity, label corpus or personal file is bundled.
