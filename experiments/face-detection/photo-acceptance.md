# Face zoom adoption gates, frozen before London inference

2026-10-16. Candidate is the official short-range version-1 detector, default score threshold 0.5, IoU NMS 0.3, maxFaces 6, pure-JS CPU in a disposable worker. Full range is a diagnostic comparator only and is not silently substituted based on this evaluation.

Intended release is optional face-box navigation on the current two comparison photos only. User explicitly chooses each face; no correspondence, scores, eye state, group, Keep, selection or export changes. Whole image and manual zoom remain usable. Missing faces are an expected limitation, especially small/profile/occluded faces.

1. Exact package and weight hashes, official Apache-2.0 evidence, notices. Photo evaluation uses creator-published consented adult London Set v5 under CC BY4.0, no demographics or ratings CSV, private local evaluation only, no photos in product or public CI artifacts.
2. Same product CSP; no network, eval or WASM allowance; normal and self-extract offline forms. Actual browser worker CPU loading/inference and cancellation/restart/failure cleanup must pass. Synthetic-only results cannot pass the photo gate.
3. London independent-subject sample: 12 indices evenly spaced over lexicographically sorted neutral-front filenames. Fixed before any inference. Pose stress sample: every other selected subject, left three-quarter and profile, 12 additional photographs of six repeated subjects. Pose rows are not additional independent subjects. Detection outputs are hidden from the visual annotator.
4. Initial usability gate: at least 11/12 frontal images produce one useful face crop, IoU at least 0.5 against approximate blinded visual face bounds, containing both creator-labelled eye centers. More than one face candidate for a one-face photo is recorded as an unwanted candidate. No invalid/non-finite/out-of-input box may reach the UI. All pose misses and extra candidates are reported; no tuning on them. Pose performance is not a broad accuracy estimate. Annotation is assistant visual review, not human-expert ground truth. Failure of the frontal criterion stops integration instead of retuning this set.
5. Before release: comparison-switch/cancel/reset late jobs cannot change view or data; worker/objectURL cleanup; current photo coordinates/EXIF orientation preserved; original File bytes/Keep/groups/ZIP invariant; keyboard and narrow EN/JA layout plus visible whole-image return. Existing normal flow must remain unlimited and independent of face detection. CI browser responsiveness and bounded timeout evidence required; physical-phone speed remains unmeasured for this new model.

This small fixed evaluation can establish a narrow experimental navigation aid only. It cannot establish consumer-burst accuracy, group-photo coverage, demographic parity, or real-phone performance. Do not report its sample proportion as a population guarantee.
